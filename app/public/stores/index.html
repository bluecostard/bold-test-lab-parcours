Sous-titre. Votre projet. Leur regard.

Description courte. Faites tester votre application ou votre site, et gagnez en visibilité en partageant des avis utiles.

Description. Gemelo relie les personnes qui créent des produits numériques à celles qui aiment les découvrir. Un entrepreneur choisit un créneau de mise en avant. Les testeurs essaient le projet, publient un avis, des captures ou une vidéo. Les likes font progresser le classement des 30 derniers jours. Les projets des testeurs du top 10 restent visibles tant qu’ils y figurent. Aucune offre ne garantit un nombre de tests.

Âge et classification

Âge dans Gemelo. 16 ans et plus. Une confirmation est demandée à la première ouverture.

Contenus. Avis, photos et vidéos publiés par les membres. Un avis peut être signalé. Un auteur peut être bloqué. Pas de violence, de nudité ni de jeux d’argent dans le service.

Achats. Créneaux payants via Stripe sur le web. Pas d’achat intégré App Store ou Play pour le moment.

Accès web. Un logo ou un lien de campagne peut ouvrir le site du projet. Apple peut classer l’app 17+ pour cet accès web. Play : contenus générés par les utilisateurs, interactions sociales, achats numériques.

Données — réponses à coller (Apple et Play)

Collecté, lié au compte. Nom, e-mail, identifiant Clerk, pseudo, projet, texte d’avis, photos, vidéos, likes, questions à un testeur, messages de contact, historique d’un créneau payé.

Non collecté. Localisation, contacts, calendrier, identifiant publicitaire, numéro de carte, CVC, données bancaires.

Partagé pour faire fonctionner le service. Clerk (connexion : nom, e-mail, identifiant). Stripe (paiement du créneau). Vercel / stockage des fichiers (avis et médias publiés).

Pas de vente de données. Pas de publicité tierce. Pas de suivi publicitaire.

Chiffrement en transit. Oui (HTTPS). Suppression : Réglages dans l’app, ou https://gemelo.online/supprimer/.

Apple Privacy Nutrition. Contact Info (Name, Email) — linked. Identifiers (User ID) — linked. User Content (Photos, Videos, Other) — linked. Purchases (Purchase History) — linked. Tracking : No.

Play Data safety. Collected : Name, Email, User IDs, Photos and videos, Other user-generated content, Purchase history. Shared : with Clerk, Stripe, hosting. Encrypted in transit : yes. Users can request deletion : yes. Data is not sold.

Encore nécessaire pour les stores

Binaire iOS. Le projet Capacitor et le fichier Codemagic sont en place (bundle online.gemelo.app). L’IPA s’ouvre sur gemelo.online/?app=1. Pas encore envoyé à l’App Store.

Achats intégrés. Dans TestFlight interne, le paiement reste Stripe web. Avant une revue App Store, il faudra les achats Apple (IAP) à la place de Stripe dans l’app.

Comptes. Apple Developer et Google Play Console au nom de Blue Costard Compagnie.

Clés live. Clerk et Stripe sont encore en mode test. Les clés live ne s’activent que lorsque vous décidez d’encaisser pour de vrai.

Codemagic — TestFlight

1. Créer l’app dans App Store Connect : nom Gemelo, bundle online.gemelo.app, société Blue Costard Compagnie.

2. Dans Apple, créer une clé API App Store Connect (accès Admin ou App Manager). Noter l’Issuer ID et le Key ID. Ne pas coller le fichier .p8 dans le chat.

3. Dans Codemagic : connecter ce dépôt, créer une intégration App Store Connect nommée exactement Gemelo, coller la clé là.

4. Variable d’environnement APP_STORE_APPLE_ID = le numéro numérique de l’app (App Store Connect → App Information).

5. Commit et push du dépôt, puis lancer le workflow « Gemelo iOS TestFlight ». Il publie sur TestFlight, pas sur l’App Store.
