Sous-titre. Votre projet. Leur regard.

Description courte. Faites tester votre application ou votre site, et gagnez en visibilité en partageant des avis utiles.

Description. Gemelo relie les personnes qui créent des produits numériques à celles qui aiment les découvrir. Un entrepreneur choisit un créneau de mise en avant. Les testeurs essaient le projet, publient un avis, des captures ou une vidéo. Les likes font progresser le classement des 30 derniers jours. Les projets des testeurs du top 10 restent visibles tant qu’ils y figurent. Aucune offre ne garantit un nombre de tests.

Catégorie. Productivité.

Âge et classification

Âge dans Gemelo. 16 ans et plus. Une confirmation est demandée à la première ouverture.

Contenus. Avis, photos et vidéos publiés par les membres. Un avis peut être signalé. Un auteur peut être bloqué. Pas de violence, de nudité ni de jeux d’argent dans le service.

Achats. Sur iOS (app native / TestFlight), les créneaux se paient uniquement via les achats intégrés Apple (StoreKit). Sur le web (gemelo.online), le paiement passe par Stripe. Pas d’achat intégré Google Play pour le moment.

Accès web. Un logo ou un lien de campagne peut ouvrir le site du projet. Apple peut classer l’app 17+ pour cet accès web. Play : contenus générés par les utilisateurs, interactions sociales, achats numériques.

Données — réponses à coller (Apple et Play)

Collecté, lié au compte. Nom, e-mail, identifiant Clerk, pseudo, projet, texte d’avis, photos, vidéos, likes, questions à un testeur, messages, historique d’un créneau payé, jeton de notification push (iOS, si autorisé).

Non collecté. Localisation, contacts, calendrier, identifiant publicitaire, numéro de carte, CVC, données bancaires.

Partagé pour faire fonctionner le service. Clerk (connexion). Apple (paiement IAP dans l’app iOS ; envoi des notifications push). Stripe (paiement du créneau sur le web uniquement). Vercel / stockage des fichiers (avis et médias publiés).

Pas de vente de données. Pas de publicité tierce. Pas de suivi publicitaire.

Chiffrement en transit. Oui (HTTPS). Suppression : Réglages dans l’app, ou https://gemelo.online/supprimer/ (purge serveur + compte Clerk).

Apple Privacy Nutrition. Contact Info (Name, Email) — linked. Identifiers (User ID) — linked. User Content (Photos, Videos, Other) — linked. Purchases (Purchase History) — linked. Other Data (device push token) — linked, used for app functionality. Tracking : No.

Play Data safety. Collected : Name, Email, User IDs, Photos and videos, Other user-generated content, Purchase history. Shared : with Clerk, Stripe (web), hosting. Encrypted in transit : yes. Users can request deletion : yes. Data is not sold.

Notes pour le reviewer App Store

Compte. Inscription ouverte via Clerk — pas de compte démo inventé. Confirmer 16 ans à l’ouverture.

Parcours à vérifier. Accueil, page campagne, publier un avis (photo / vidéo), signaler, bloquer, messagerie (après paiement), Réglages (notifications, données, suppression de compte), Contact.

Paiement iOS. Utiliser un compte Sandbox App Store (Réglages iOS → App Store → Compte Sandbox). Dans Gemelo : profil → Faire tester mon service → choisir une offre → payer avec la feuille Apple (StoreKit). Stripe n’est pas utilisé dans l’app iOS. Après achat, la campagne doit apparaître et le créneau être confirmé.

Produits Sandbox. Les IDs listés ci-dessus (online.gemelo.slot.*). Consommables.

Notifications. L’app peut demander l’autorisation push pour « Nouvelle campagne » et « Classement » (facultatif, réglages).

Suppression. Réglages → Supprimer mon compte : purge les données serveur Gemelo puis ferme Clerk.

Page introuvable. https://gemelo.online/introuvable/ ou https://gemelo.online/?app=1&ecran=inconnu

Web. Stripe reste le paiement sur gemelo.online hors app native.
