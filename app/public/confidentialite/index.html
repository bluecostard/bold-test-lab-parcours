Confidentialité

Dernière mise à jour : 13 octobre 2026.

Cette page décrit les données traitées par Gemelo, service accessible à gemelo.online. Elle vaut politique de confidentialité.

Responsable. Blue Costard Compagnie (SIRET 109 416 958 00014), éditeur de Gemelo, joignable via gemelo.online/contact/, Réglages → Contact, ou Instagram et TikTok @bluecostard.

Âge. Le service est réservé aux personnes de 16 ans et plus. La confirmation d’âge est enregistrée sur l’appareil.

Compte. La connexion est assurée par Clerk. Clerk reçoit le nom, l’e-mail et un identifiant de compte. Sans compte, vous pouvez consulter le site ; tester et payer exigent une connexion.

Profil. Le pseudo public, le projet et l’offre choisie sont enregistrés dans le navigateur, liés à votre compte. Une campagne payée est aussi enregistrée côté serveur pour afficher la page et les résultats.

Messages. Les échanges entre propriétaires de campagnes payantes sont hébergés pour le service. Ils ne sont visibles que des participants à la conversation.

Avis. Le texte, les photos et les vidéos d’un avis publié sont hébergés pour les montrer aux autres membres et à l’entrepreneur. Un like est enregistré sans que vous puissiez aimer votre propre avis.

Paiement. Sur le site web, Stripe traite le paiement du créneau. Dans l’application iOS, le paiement passe par les achats intégrés Apple (StoreKit) ; Apple agit comme intermédiaire de paiement. Gemelo ne stocke pas le numéro de carte, le CVC ni les données bancaires.

Notifications push. Sur iPhone, si vous autorisez les notifications, un jeton d’appareil est enregistré pour envoyer les alertes facultatives « Nouvelle campagne » et « Classement ». Vous pouvez refuser ou couper ces alertes dans Réglages → Notifications.

Demandes de créneau. Le formulaire /besoin envoie le nom du projet, le lien et l’e-mail professionnel pour recontacter le demandeur. Aucun paiement n’est pris sur ce formulaire.

E-mails obligatoires. Gemelo envoie, sans option de refus dans l’app : (1) bienvenue à l’inscription, (2) confirmation de campagne après paiement, (3) question d’un entrepreneur sur votre avis, (4) nouveau message entre propriétaires de campagnes payantes, (5) confirmation de modification ou d’annulation de créneau. Ces messages partent de bonjour@gemelo.online.

E-mails facultatifs. Nouvelle campagne, classement hebdomadaire et dernière ligne droite (4 h) se gèrent dans Réglages → Notifications, ou via le lien de désinscription des messages concernés. L’adresse utilisée est celle du compte Clerk. Nouvelle campagne et classement peuvent aussi partir en push iPhone.

Durée. Les données de compte et d’avis restent tant que le compte existe, ou jusqu’à ce que l’avis soit retiré. Les brouillons restent dans le navigateur de l’appareil.

Vos droits. Vous pouvez consulter et modifier votre profil dans l’application. Vous pouvez télécharger une copie des données de cet appareil depuis Réglages → Mes données. Vous pouvez supprimer votre compte depuis Réglages, ou depuis gemelo.online/supprimer/ : cela efface vos données Gemelo sur le serveur (campagnes, avis, messages, médias, notifications), les données locales de l’appareil, puis ferme le compte Clerk.

Cookies. Clerk dépose des cookies ou un stockage de session pour maintenir la connexion. Gemelo n’utilise pas de publicité tierce.

Transferts. Clerk, Apple et Stripe peuvent traiter des données hors Union européenne, selon leurs propres garanties. Consultez clerk.com, apple.com/privacy et stripe.com.
