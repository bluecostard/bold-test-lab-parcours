Supprimer mon compte

Cette page décrit comment fermer un compte Gemelo. La suppression est définitive pour le compte de connexion.

Depuis l’application

Ouvrez Réglages, connectez-vous, puis choisissez « Supprimer mon compte ». Les données Gemelo enregistrées sur cet appareil sont effacées. Le compte Clerk est fermé.

Si vous ne pouvez pas vous connecter

Écrivez depuis gemelo.online/contact/ avec l’e-mail du compte. Nous traitons la demande de fermeture.

Ce qui est effacé, ce qui peut rester

La suppression ferme le compte et vide les données locales de l’appareil. Un avis déjà publié peut rester visible tant qu’il n’est pas retiré : demandez-le dans le même message de contact si vous voulez qu’il disparaisse.

Avant de supprimer, vous pouvez télécharger une copie depuis Réglages → Mes données.
